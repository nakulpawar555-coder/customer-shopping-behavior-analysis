# Customer Shopping Behavior Analysis

## Overview

This project analyzes customer shopping behavior using transactional data from **3,900 purchases** across multiple product categories.

The objective is to understand customer spending patterns, product preferences, discount usage, customer segments, and subscription behavior to support data-driven business decisions.

The project follows an end-to-end data analytics workflow, from data loading and cleaning to SQL analysis, dashboard development, and reporting.

## Dataset

The dataset contains **3,900 rows and 18 columns**.

Key information includes:

- **Customer demographics:** Age, gender, location, and subscription status
- **Purchase details:** Item purchased, category, purchase amount, season, size, and color
- **Shopping behavior:** Discount usage, previous purchases, purchase frequency, review ratings, and shipping type

**Data quality:** The original dataset contained 37 missing values in the Review Rating column. These were handled using the median rating for each product category.

## Project Workflow

### 1. Data Loading and Exploration

- Imported the dataset into Python using Pandas.
- Examined the dataset structure using `df.info()`.
- Generated summary statistics using `df.describe()`.
- Checked for missing values and reviewed data consistency.

### 2. Data Cleaning and Feature Engineering

- Handled missing review ratings using category-wise median imputation.
- Standardized column names using snake_case.
- Created an `age_group` column by grouping customer ages.
- Created a `purchase_frequency_days` column from purchase data.
- Checked for redundancy between discount and promo code fields.
- Removed the redundant `promo_code_used` column.
- Loaded the cleaned DataFrame into PostgreSQL for further analysis.

### 3. SQL Business Analysis

Used SQL queries to answer the following business questions:

1. **Revenue by Gender:** Compared revenue generated by male and female customers.
2. **High-Spending Discount Users:** Identified customers who used discounts but spent above the average purchase amount.
3. **Top 5 Products by Rating:** Identified products with the highest average review ratings.
4. **Shipping Type Comparison:** Compared average purchase amounts for Standard and Express shipping.
5. **Subscribers vs. Non-Subscribers:** Compared customer counts, average spending, and total revenue.
6. **Discount-Dependent Products:** Identified products with the highest percentage of discounted purchases.
7. **Customer Segmentation:** Classified customers into New, Returning, and Loyal segments.
8. **Top Products by Category:** Identified the most-purchased products within each category.
9. **Repeat Buyers and Subscriptions:** Examined repeat buyers with more than five purchases and their subscription status.
10. **Revenue by Age Group:** Compared total revenue across customer age groups.

### 4. Power BI Dashboard

Developed an interactive Power BI dashboard to present key metrics and trends.

The dashboard includes:

- Total number of customers
- Average purchase amount
- Average review rating
- Customer distribution by subscription status
- Revenue and sales by product category
- Revenue and sales by age group
- Filters for customer demographics, categories, subscription status, and shipping type

### 5. Reporting and Presentation

- Created a project report documenting the methodology, SQL analysis, dashboard, and business recommendations.
- Prepared a presentation using Gamma to communicate the project findings in a clear, visual format.

## Key Results

The analysis produced the following findings:

- **Customer revenue:** Male customers generated 157,890 in revenue, compared with 75,191 for female customers.
- **Product ratings:** Gloves had the highest average rating among the five products analyzed, at 3.86.
- **Shipping:** Express shipping had a higher average purchase amount (60.48) than Standard shipping (58.46).
- **Subscription status:** The dataset contained 1,053 subscribers and 2,847 non-subscribers.
- **Discount usage:** Hats had the highest discount rate among the five products analyzed, at 50%.
- **Customer segments:** 3,116 customers were classified as Loyal, 701 as Returning, and 83 as New.
- **Age groups:** Young Adults contributed the highest total revenue among the age groups analyzed, at 62,143.

These findings describe the analyzed dataset and can help guide further investigation into customer retention, promotions, and product positioning.

## Business Recommendations

Based on the analysis:

- **Boost subscriptions:** Promote relevant benefits to encourage subscription adoption.
- **Improve customer loyalty:** Reward repeat buyers and strengthen retention initiatives.
- **Review discount policies:** Balance promotional effectiveness with profitability.
- **Improve product positioning:** Highlight highly rated and best-selling products in marketing campaigns.
- **Use targeted marketing:** Focus campaigns on high-revenue age groups and evaluate shipping preferences.

## How to Run

### Prerequisites

Install or prepare the following tools:

- Python 3.x
- Jupyter Notebook
- Pandas
- PostgreSQL and a database client such as pgAdmin
- Power BI Desktop

### Steps

1. Clone or download this repository.
2. Install the required Python library:

   ```bash
   pip install pandas sqlalchemy psycopg2-binary
   ```

3. Open `Customer_shopping_Analysis.ipynb` in Jupyter Notebook.
4. Update the dataset path in the notebook to match your local file location.
5. Run the notebook cells to explore, clean, and prepare the data.
6. Create a PostgreSQL database and configure your database connection.
7. Execute the SQL queries in `sql.sql` against the prepared database. Update table names if necessary.
8. Open `Customer_behavior.pbix` in Power BI Desktop and configure the data source if prompted.
9. Refer to the PDF report and presentation for the documented analysis and findings.

**Database note:** The documented workflow uses PostgreSQL. MySQL and SQL Server are possible alternatives, but their connection settings and SQL syntax may require changes.
